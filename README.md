# SeriesHub — GitHub Pages + Decap CMS Theme

## Quick setup
1. Upload all files to a GitHub repository.
2. Edit `admin/config.yml` and replace `YOUR_GITHUB_USERNAME/YOUR_REPOSITORY`.
3. Enable GitHub Pages from Settings → Pages → Deploy from branch → `main`.
4. Open `/admin/` on your deployed site.
5. For Decap CMS GitHub authentication, configure an OAuth/auth provider suitable for your deployment. Do not put private tokens in frontend files.
6. Replace demo content and image URLs with your own legally published/licensed material.
7. Update `robots.txt` and `sitemap.xml` with your real domain.

## Theme
Dark, responsive catalog layout with homepage, trending/latest sections, search, genres, series detail page, seasons/episodes, and age gate.

## Important
The sample data is only placeholder content. The theme does not include copyrighted video files or streaming/download functionality.
